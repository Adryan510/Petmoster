
# 🐾 PetMoster

Site institucional de pet shop desenvolvido como projeto acadêmico
durante meus estudos de Front-end.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## ✨ Funcionalidades

- Navegação entre as seções do site
- Apresentação do pet shop
- Galeria de imagens
- Mapa incorporado
- Formulário de contato com validação básica

## 🎯 Objetivo

Praticar a estruturação de páginas com HTML e a estilização
de interfaces com CSS.

## 🚀 Como executar

Clone ou baixe este repositório e abra o arquivo `index.html`
no navegador.

## 🌐 Site publicado

Adicione aqui o link do site quando publicar pelo GitHub Pages.

## 📚 Aprendizados

Este projeto me ajudou a praticar a organização de páginas HTML,
a criação de estilos CSS e a construção de um site institucional.
